Cara Download Video TikTok di iPhone dan Menyimpannya ke Foto

29 Oktober 2026 · Tim UnduhTik

Di iPhone, file yang diunduh melalui browser tidak selalu langsung muncul di aplikasi Foto. Biasanya file lebih dulu berada di aplikasi File, sehingga ada satu langkah tambahan untuk menyimpannya ke galeri. Ikuti alur berikut untuk menyalin tautan TikTok, membukanya di Safari, lalu menemukan video di perangkat.

Sebelum mulai, pastikan Safari dapat membuka situs dan iPhone memiliki ruang penyimpanan yang cukup. Antarmuka bisa sedikit berbeda antarversi iOS; gunakan nama folder dan menu yang tampil di perangkat Anda, bukan mengandalkan letak tombol dari tangkapan layar lama.

Ilustrasi tampilan konseptual di Safari, bukan tangkapan layar iPhone.

Salin tautan dan buka Safari

  1. Buka video yang dapat Anda akses di aplikasi TikTok.
  2. Ketuk Bagikan, lalu pilih Salin Tautan.
  3. Buka Safari secara langsung. Jika tautan UnduhTik dibuka di dalam TikTok atau aplikasi lain, pilih opsi untuk membukanya di browser.
  4. Kunjungi UnduhTik, tempel tautan ke kolom yang tersedia, lalu ketuk Unduh.
  5. Pilih hasil video yang tersedia untuk tautan tersebut dan ikuti instruksi Safari untuk menyimpannya.

Nama dan letak kontrol dapat sedikit berbeda menurut versi iOS dan browser. Jika satu tombol tidak terlihat, periksa menu Bagikan atau unduhan Safari alih-alih mengulang proses berkali-kali.

Jika tautan terbuka kembali di aplikasi TikTok, ketuk menu Bagikan pada halaman tersebut dan pilih opsi untuk membuka di Safari. Setelah halaman UnduhTik dimuat, tempel tautan hanya satu kali, lalu tunggu respons. Tahap pemrosesan tautan dan tahap penyimpanan file adalah dua proses terpisah; catat di tahap mana masalah terjadi.

Temukan file di aplikasi File

Setelah unduhan dimulai, buka aplikasi File dan masuk ke Telusuri → Unduhan atau folder yang Anda pilih sebagai lokasi unduhan Safari. Cari file terbaru berdasarkan waktu. Ketuk file untuk memastikan video dapat diputar sebelum memindahkannya.

Di Safari, Anda juga dapat membuka daftar unduhan dari kontrol unduhan browser jika terlihat. Dari sana, pilih file untuk melihat pratinjau atau membuka lokasinya di File. Jika Anda mengubah lokasi unduhan Safari sebelumnya, periksa lokasi pilihan tersebut, bukan hanya folder iCloud Drive.

Ilustrasi alur penyimpanan; nama menu dapat berbeda di tiap versi iOS.

Simpan video ke aplikasi Foto

Jika video sudah berada di File, ketuk file tersebut lalu buka menu Bagikan. Pilih Simpan Video bila opsi itu tersedia. Setelah proses selesai, buka Foto dan periksa pustaka atau album Terbaru. Jika pilihan tersebut tidak muncul, periksa format file dan coba membukanya lebih dahulu dari File.

Anda tidak harus memindahkan setiap file ke Foto. Jika hanya ingin menyimpan file untuk ditonton, menyimpannya di File juga dapat memudahkan pengelolaan folder. Pilih lokasi yang mudah ditemukan dan hapus salinan yang tidak diperlukan untuk menghemat ruang.

Jika tombol Bagikan tidak langsung terlihat saat video sedang diputar, ketuk layar sekali untuk menampilkan kontrol atau buka file dari File. Pastikan Anda memilih tindakan untuk menyimpan video, bukan hanya menyalin tautan file. Setelah menyalin ke Foto, file di folder Unduhan dapat tetap ada sebagai salinan terpisah.

Jika Safari tidak menyimpan video

  • Pastikan unduhan benar-benar selesai; file yang masih diproses mungkin belum bisa diputar.
  • Periksa lokasi unduhan Safari dan ruang penyimpanan perangkat.
  • Salin ulang tautan langsung dari TikTok dan pastikan video masih dapat dibuka.
  • Coba lagi melalui Safari penuh, bukan browser tertanam di aplikasi sosial.
  • Jika tautan gagal diproses, ikuti langkah pemeriksaan unduhan gagal.

Safari dapat menyimpan file ke iCloud Drive atau ke penyimpanan iPhone, tergantung pengaturan unduhan yang dipilih. Jika folder Unduhan tampak kosong, periksa lokasi pilihan Safari di pengaturan perangkat dan telusuri folder tersebut di File. Jangan menganggap file hilang sebelum memeriksa daftar unduhan browser.

Apabila video terbuka sebagai pratinjau, coba gunakan menu Bagikan pada pemutar dan pilih tindakan simpan yang tersedia. Jika Safari menampilkan ikon unduhan, periksa statusnya terlebih dahulu. File yang masih berlangsung dapat belum terlihat pada Foto maupun belum bisa diputar.

Perhatikan juga aplikasi tempat Anda membuka tautan. Tautan yang dibuka dari browser dalam aplikasi media sosial dapat memiliki kontrol yang berbeda dari Safari. Jika tombol unduh atau daftar file tidak muncul, salin tautannya dan buka Safari secara langsung. Cara ini membantu membedakan masalah tampilan dalam aplikasi dari masalah file.

Sebelum mengulang proses, cek ruang penyimpanan iPhone dan koneksi jaringan. Unduhan besar dapat berhenti jika ruang hampir habis atau koneksi berpindah. Setelah file selesai, putar dari File terlebih dahulu; baru gunakan opsi simpan ke Foto bila Anda memang ingin video muncul di pustaka tersebut.

Jika Anda memakai mode penjelajahan privat atau pengaturan pembatasan konten, beberapa perilaku browser mungkin berbeda. Coba jendela biasa terlebih dahulu dan perhatikan pesan yang muncul, tanpa menonaktifkan perlindungan perangkat secara luas. Bila perangkat dikelola kantor atau keluarga, pembatasan dapat ditetapkan oleh administrator dan perlu ditanyakan kepada mereka.

Untuk masalah file yang sudah tersimpan tetapi tidak terlihat di galeri, baca panduan mencari video di galeri.

Pertanyaan umum pengguna iPhone

Apakah video langsung masuk ke Foto?

Belum tentu. Unduhan Safari biasanya dapat ditemukan dari daftar unduhan atau aplikasi File. Gunakan Bagikan → Simpan Video bila ingin menyalinnya ke Foto.

Mengapa pilihan Simpan Video tidak terlihat?

Periksa apakah file sudah selesai diunduh dan dapat diputar. Format, versi iOS, dan jenis file dapat memengaruhi opsi yang tersedia.

Bagaimana jika penyimpanan iCloud penuh?

Periksa lokasi unduhan dan ruang kosong yang tersedia. Anda dapat memilih lokasi lain yang didukung atau mengosongkan ruang, lalu mencoba menyimpan file setelah memastikan unduhan sebelumnya tidak sedang berlangsung.

Perhatikan hak penggunaan

Video yang disimpan tetap milik pembuatnya. Gunakan secara bertanggung jawab, jangan membagikan ulang tanpa izin, dan hormati privasi serta hak cipta. UnduhTik tidak berafiliasi dengan TikTok.
