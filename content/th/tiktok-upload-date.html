เหตุใด ID ของวิดีโอจึงแสดงวันที่

ID ของวิดีโอ TikTok ถูกกำหนดตามลำดับเวลา ส่วนแรกของตัวเลขเก็บเวลาที่สร้างวิดีโอในรูปแบบ Unix คือจำนวนวินาทีนับจากวันที่ 1 มกราคม 1970 เครื่องมือนี้ดึงส่วนนั้นออกมาแล้วแปลงเป็นวันที่ที่อ่านได้ การคำนวณทั้งหมดทำในเบราว์เซอร์ของคุณ ไม่ต้องติดต่อ TikTok

ผลลัพธ์หมายความว่าอย่างไร

ผลลัพธ์แสดงเวลาที่วิดีโอถูกสร้างขึ้น คุณจะเห็นเวลาสองแบบ คือเวลาในอุปกรณ์ของคุณซึ่งตามเขตเวลาของคุณ และเวลา UTC ซึ่งเหมือนกันสำหรับทุกคน บรรทัด "เมื่อนานเท่าไหร่แล้ว" นับจากเวลาปัจจุบัน ค่านี้จึงเปลี่ยนทุกครั้งที่ตรวจสอบ

ผลลัพธ์ไม่แสดงจำนวนการเข้าชม ยอดไลก์ หรือข้อมูลบัญชี เครื่องมือนี้อ่านเฉพาะวันที่ที่เก็บอยู่ใน ID

เมื่อวันที่ดูไม่ถูกต้อง

หากขึ้นข้อความว่า ID นี้ให้วันที่ที่ไม่สมเหตุสมผล ให้ตรวจว่าคุณคัดลอก ID หรือที่อยู่เต็มของวิดีโอ ไม่ใช่ลิงก์สั้น วิดีโอที่ถูกแก้ไขหรืออัปโหลดใหม่อาจแสดงวันที่เก่ากว่าที่คาด เพราะ ID สะท้อนเวลาที่สร้างครั้งแรก

ความเป็นส่วนตัว

การตรวจสอบทำงานในเบราว์เซอร์ของคุณ วันที่ถูกคำนวณบนอุปกรณ์ของคุณจาก ID ที่คุณวาง อย่าวางข้อมูลส่วนตัวลงในช่องนี้
